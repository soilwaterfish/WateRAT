The workflow

From state records to a defensible flowline result

1. Prepare incrementally

State adapters filter and standardize PODs; Idaho reuses prior report scrapes where the POD is unchanged.

2. Cache the handoff

COMIDs and FS ownership are stored in one prepared multi-state GeoPackage.

3. Route and review

One network pipeline carries allocations across state borders and writes reviewable GIS output.

Two targets pipelines, one result. Run prep_targets.R with the separate _targets_prep store when source data change. Then run _targets.R normally to route the one prepared layer across every included state.

Two methods, one output language

Retrieves an upstream NLDI basin per reporting COMID, then calls capture_sites_within(). It remains the validation baseline.

Assigns PODs once, sums allocations by COMID, and propagates them through NHDPlus edges. The final field names match the basin output for line-by-line validation.
