--- title: Small-scale walkthrough ---

Learn by running it

Walk through two small basins before scaling up.

This package includes one Montana and one Idaho basin plus their clipped NHDPlus routing network. Use them to inspect each function's input and output before moving state preparation into prep_targets.R and connected routing into _targets.R.

What ships with WaterRAT. pod_example_basins.gpkg contains the two labeled AOIs and NHDFlowline_Network. Water-right source data, FlowMet, and ownership data remain local authoritative inputs.

1. Load and choose an AOI

library(WaterRAT)

fixture <- system.file("extdata", "pod_example_basins.gpkg", package = "WaterRAT")
example_basins <- sf::read_sf(fixture, layer = "pod_example_basins")

mt_aoi <- dplyr::filter(example_basins, state_code == "MT")
id_aoi <- dplyr::filter(example_basins, state_code == "ID")
example_basins

The layer has stable state_code and example_basin fields. Start with either row, then use both when checking cross-state behavior.

2. Retrieve and standardize PODs

mt_pods <- get_mtwr(
  filter_geom = mt_aoi, layer = "WRQS_PODS",
  local_path = "data/WRQS_Dataset_GDB.gdb"
) |>
  date_cleaning()

mt_candidates <- standardize_mt_pod_candidates(mt_pods)

id_rights <- get_idwr_pods(
  local_path = "data/idwr.gdb", filter_geom = id_aoi
) |>
  expand_idwr_pods_by_use() |>
  standardize_idwr_water_rights() |>
  filter_water_rights_month(month = 8)

validate_water_rights(mt_candidates)
validate_water_rights(id_rights)

Montana candidates are indexed and reduced to one downstream-most POD per WRKEY in the next step. Idaho is already ready for shared analysis.

3. Read the matching routing network

network <- read_nhdplus_flowlines(
  path = fixture,
  filter_geom = example_basins,
  layer = "NHDFlowline_Network"
)

catchments <- read_nhdplus_catchments(
  path = "data/NHDPlusNationalData/NHDPlusV21_National_Seamless_Flattened_Lower48.gdb",
  filter_geom = example_basins
)

network[, c("comid", "hydroseq", "dnhydroseq", "streamorde", "qe_08")]

This explicitly reads the fixture's NHDFlowline_Network layer using the same source-filtered reader used for a national local NHDPlus geodatabase. The fixture is small enough to map and inspect, while retaining the real routing fields.

4. Select Montana's downstream-most POD

mt_comid_index <- index_water_right_comids(
  mt_candidates,
  catchments = catchments,
  cache_path = "data/mt_pod_example_comids.rds",
  workers = 1,
  throttle_seconds = 0.5
)

mt_rights <- select_mt_downstream_pods(
  mt_pods, mt_comid_index, network
) |>
  standardize_mt_water_rights()

water_rights <- dplyr::bind_rows(mt_rights, id_rights)

The lowest hydroseq is downstream. A group that cannot be linked to the local network is explicitly marked lowest_pod_id_fallback for review.

5. Index PODs and aggregate their local allocation

comid_index <- index_water_right_comids(
  water_rights,
  catchments = catchments,
  cache_path = "data/pod_example_comids.rds",
  workers = 1,
  throttle_seconds = 0.5
)

local_allocations <- aggregate_local_allocations(water_rights, comid_index)
local_allocations

Inspect nldi_error before continuing. Every indexed POD should have a COMID or an explicit reason it could not be assigned.

6. Route allocations downstream

accumulated <- accumulate_downstream_allocations(network, local_allocations)

reportable_reaches <- filter_reportable_reaches(
  accumulated,
  minimum_streamorder = 2
)

reportable_reaches

First-order reaches remain in accumulated so their local allocations can propagate downstream. Apply the reporting threshold only afterward.

7. Add FlowMet and compare to the basin method

# Read and clip your local FlowMet source to example_basins, then:
final_join <- format_capture_sites_output(
  accumulated_network = reportable_reaches,
  flowmet = flowmet_aoi
)

sf::write_sf(final_join, "data/pod_example_final.gpkg", delete_dsn = TRUE)

For validation, run the established NLDI-basin path for the same AOI and compare the final allocation fields. Once the small result agrees with expectations, encode the state-specific preparation in prep_targets.R, then use the Targets framework to route the combined prepared layer.
