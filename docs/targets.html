--- title: Targets framework ---

Reproducible execution

One prepared layer. One connected network.

State-specific preparation happens before this pipeline. A dedicated prep script maintains the cache; this analysis script reads one combined, validated POD GeoPackage and routes allocations through one NHDPlus network, so allocation can continue across the states represented in the cache.

1

Prepare by state

Run prep_targets.R to filter, scrape incrementally, standardize, assign COMIDs, and classify FS/private ownership.

2

Upsert one cache

The final prep target is the sole file owner of water_rights.gpkg; state targets return paths, so one state’s upsert does not invalidate another.

3

Route all states

_targets.R reads the combined simple-feature layer, builds one network, and accumulates across state borders.

Annual refresh pattern. Run targets::tar_make(script = "prep_targets.R", store = "_targets_prep") only when source data need refreshing. Idaho reuses stable report scrapes; both states reassign POD COMIDs locally from the AOI-filtered NHDPlus catchments; NLDI is called only for an unresolved point.
