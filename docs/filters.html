--- title: State adapters and filtering ---

Input preparation

Filter first. Scrape second.

Each adapter reduces state data to relevant, comparable POD records before shared analysis begins.

Montana

Surface-water PODs for August

  • Active right status
  • Non-missing MAX_FLOW_CFS
  • Surface-water source type
  • For repeated WRKEYs, retain the POD with the lowest NHDPlus hydroseq

WR_NUMBER is the canonical right ID and WRKEY is the canonical site ID. The selected POD, COMID, candidate count, and selection method remain available as audit fields.

Idaho

Filter, then expand uses

  • Spatial boundary and active status
  • Configurable source/status exclusions
  • Ground water normally excluded
  • Beginning-of-stream-flow (B) locations excluded; Ending locations retained
  • One record for each Water Uses row

The report TOTAL row is excluded. Rate and volume text become numeric values plus preserved reported units.

August is intentional

filter_water_rights_month(month = 8) retains annual records plus records whose reported diversion period overlaps August. When a POD has multiple August segments, their reported rates are averaged into one site. A January-only rate does not enter an August allocation calculation.

Ownership classification

fs_logic() adds fs_intersection by intersecting POD points with USDA Forest Service ownership polygons. It is an ownership split—not a water-right status—and produces the final Forest Service/private fields.
