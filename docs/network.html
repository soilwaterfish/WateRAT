Read the local NHDPlus Catchment layer with the same AOI filter used for flowlines, then intersect each POD once. The catchment FEATUREID is the associated flowline COMID. NLDI hydrolocation is retained only as a paced, checkpointed fallback for a POD with no single local catchment match.

catchments <- read_nhdplus_catchments(
  path = "data/NHDPlusNationalData/NHDPlusV21_National_Seamless_Flattened_Lower48.gdb",
  filter_geom = analysis_aoi
)

index_water_right_comids(
  water_rights,
  catchments = catchments,
  cache_path = "data/state_hydrolocation.rds",
  workers = 1L,
  throttle_seconds = 0.5,
  retries = 3L
)

Route correctly

At a confluence, upstream totals are added. At a divergence, totals propagate along every supplied downstream path. A cycle in the supplied network is an error.

Fetch all orders before accumulation. A POD on a first-order reach must contribute downstream. Apply filter_reportable_reaches(minimum_streamorder = 2) only after routing.
The formatter intentionally produces the same all/instream/non-instream and Forest Service/private field names as capture_sites_within(). That is what makes the two methods directly comparable.
