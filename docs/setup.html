--- title: Setup and local data ---

Get started

Set up a local analysis workspace

WaterRAT version-controls code and documentation—not large source datasets or derived results.

1

Install

remotes::install_github("soilwaterfish/WaterRAT")
2

Place data locally

Keep geodatabases, GeoPackages, caches, and scratch work beneath ignored data/ and dev/ paths.

3

Run a check

WATERRAT_RUN_MODE=smoke Rscript -e 'targets::tar_make()'
